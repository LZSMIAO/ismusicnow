# MUISM MyHK 六平台接入審計

日期：2026-10-05。基線：642662d3b3e4b9c4705ffe0ea034aca90c219e84。

## 接入範圍

MyHK 作為網易雲、QQ、酷我、酷狗、咪咕、千千的主接口。網站、Telegram 私聊／群組、Inline、歌曲下載、平台歌詞、来源筛选、音樂卡片與 Telegram 快取共用同一適配路由。Spotify、YTM 與原有公開音源維持獨立來源。

| 能力 | 實作 |
| --- | --- |
| 歌曲關鍵字 | 六平台並行搜尋；單平台失敗不阻塞其他結果 |
| 專輯連結 | 網易、QQ、酷我 |
| 歌單連結 | 網易、QQ、酷我、酷狗 |
| 專輯／藝術家／歌單關鍵字 | 新平台 API 沒有此能力，按實際能力收起分類；原網易與 Spotify 路徑保留 |
| 網易兜底 | 主接口失敗、空結果、缺少必要元資料、失效 CDN、無效或不完整音訊時回原接口；原生 FLAC 請求使用可提供無損的原接口 |
| Inline | 支援 QQ 14 字元 ID、酷狗 32 字元 hash；選中後原訊息替換成播放器；多平台選單每行最多三個來源 |
| 音源與格式 | 保存平台提供檔案，解析真實編碼；MP3 不再次轉碼；不將其他平台匹配音源冒充選定來源 |
| 快取 | MyHK 音源使用獨立品質鍵，避免與舊無損引用混淆；保留現有 Telegram 本地 Bot API 大檔配置 |

## 安全與成本控制

密鑰只放服務端 MYHK_API_KEY，POST 表單傳給固定 HTTPS origin，禁止接口重定向；不在 API URL、前端、git、審計或日誌中保存密鑰。已授權加密傳到 MUISM VPS 的 .env，權限 600。各平台 CDN 白名單連同重定向一起驗證；下載串流檢查大小。列表／元資料請求合併並有限快取，失败短暫合併，避免 Inline 重複輸入消耗配額。只有搜索等实际请求使用控制台已有包量，沒有購買新套餐。
